# Structure of RIB 
167,229,32,134-pub -> 167,229,32,134,143,191,106,193,89,194,153,70 = topic_guid,publisher_guid,subscriber_guid
167,229,32,134-sub -> 214,82,144,174 = subscriber_guid

# How RIB Pub-Sub Works
1. Subscriber announces: adds its GUID to {topic}-sub list
2. Publisher watches {topic}-sub, creates full signaling URL for each subscriber
3. Publisher adds signaling URL to {topic}-pub list
4. Subscriber watches {topic}-pub for URLs ending with its GUID
5. When match found, both establish WebRTC connection using signaling server
6. Redis keyspace notifications enable dynamic discovery of new publishers/subscribers
